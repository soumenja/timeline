    GitHub connection

    Saving writes the encrypted file data/timeline.enc.json to your repository. The token is kept only in this browser on this device.

    How to make a token
    1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Repository access: Only select repositories → pick this timeline repo.
    3. Permissions → Repository permissions → Contents: Read and write. Nothing else.
    4. Generate, copy it, and paste it here.

    Change passphrase

    The new passphrase applies the next time you press Save.

    Help & shortcuts

    • Drag the timeline to move it. Scroll or pinch to zoom.
    • Double-click an empty spot to add an event on that date.
    • Click an event to see details, edit or delete it.
    • Click or drag the overview strip at the bottom to jump.
    • ← → move · ↑ ↓ scroll up/down · + − zoom
    • N new event · L list · F show all · T today · Ctrl+S save
    • Changes stay in this tab until you press Save. The public site shows the new version about a minute later.
